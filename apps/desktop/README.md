# FSM Designer 桌面版（Tauri 2）

編輯器本體在 `apps/editor`（React + Vite），這裡只是 Tauri 外殼：原生開檔/存檔對話框、讀寫本機檔案、視窗標題與關閉前提醒。

## 執行

需要 Node 22.18 以上、pnpm 10、Rust（`rustup`），以及 [Tauri 的系統需求](https://tauri.app/start/prerequisites/)（Windows 需 WebView2，macOS 需 Xcode Command Line Tools，Linux 需 webkit2gtk-4.1）。

```sh
pnpm install
pnpm dev            # 開發模式：開啟桌面視窗，修改程式即時更新
pnpm bundle         # 產生安裝檔，位於 apps/desktop/src-tauri/target/release/bundle/
pnpm dev:web        # 不開 Tauri，只在瀏覽器跑編輯器（http://localhost:5173）
```

## 操作（同 madebyevan.com/fsm）

| 動作 | 操作 |
| --- | --- |
| 新增狀態 | 在空白處雙擊 |
| 接受狀態（雙圈） | 雙擊狀態 |
| 移動狀態 | 拖曳；靠近其他狀態的圓心水平/垂直線時自動對齊並顯示粉紅虛線，否則吸附到格線（按住 Alt 自由放置） |
| 格線 / 吸附 | 狀態列選 Line（預設）、Dot 或 None；「Snap」開關吸附（格距 20，每 5 格加粗） |
| 對齊多個狀態 | 多選後在右側面板按「水平對齊／垂直對齊／水平等距／垂直等距」 |
| 新增轉移 | Shift + 從狀態拖到另一個狀態（新線條沒有文字，畫面只顯示你打的字） |
| 自迴圈 | Shift + 從狀態拖出後放回自己或旁邊，方向跟著滑鼠 |
| 起始箭頭 | Shift + 從空白處拖到狀態 |
| 彎曲轉移線 | 拖曳線段；拖回接近直線會自動變直。右側面板「直線／曲線」切換，曲線時可按「重設彎曲」；來回兩條都是直線時會平行錯開，可調「兩線間距」 |
| 調整自迴圈/起始箭頭方向 | 拖曳它 |
| 編輯文字 | 選取後直接打字，方向鍵移動游標；`S_0` 或 `\beta` 後按空白變成 S₀、β |
| 框選 / 全選 | Ctrl + 拖曳（往右拉：藍色實線框，只選完整框住的物件；往左拉：綠色虛線框，碰到就選；會加入原本的選取） / Ctrl+A；Ctrl + 點一下加入或移出選取 |
| 調整圓圈大小 | 選取狀態後拖曳右下角的方形把手，或在右側面板輸入半徑 |
| 字體大小 | 右側面板（多選時一次套用到全部） |
| 複製 / 剪下 / 貼上 | Ctrl+C / Ctrl+X / Ctrl+V（狀態連同它們之間的線條一起複製） |
| 刪除 | 選取後按 Delete |
| 復原 / 重做 | Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y） |
| 開啟 / 儲存 / 另存 | Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| 平移 / 縮放 | 拖曳空白處或捲動滾輪 / Ctrl + 滾輪（每格 10%），工具列顯示目前比例，點比例回到 100% |
| 符合視窗 | F（沒有選取狀態或線條時）或工具列「符合視窗」 |

底部狀態列右邊的「Hints」會在畫布上打開完整的快捷鍵表；格線樣式、吸附、縮放也在狀態列。

右側面板可以用一般輸入框改文字（中文輸入法請用這裡）、接受/起始狀態。

右上角的地球圖示可以切換介面語言（English / 中文 / 日本語，預設英文），選擇會被記住。

匯入 Verilog（File ▸ Import Verilog…，Ctrl+I）：貼上或開啟 `.v` / `.sv`，會用演算法分析程式碼（不是 AI 猜測），找出狀態暫存器、reset 狀態、每條轉移的條件與輸出，自動排版後畫成一張新的圖。只跟狀態有關的輸出畫在狀態圓圈裡（Moore），也跟輸入有關的輸出畫在轉移線上「條件 / 輸出」（Mealy）；畫布左下角會列出找到的狀態編碼、reset 與輸出分類。支援的寫法見 `packages/core/src/import/README.md`。

自動排版（File 按鈕旁的按鈕）：用同一套規則把所有狀態重新排整齊，沒有選項，依圖的結構決定，不看狀態數量。互不相連的子圖各自排好再並排，重設狀態那一塊在最前面；從重設狀態走不到的狀態用虛線外框標示。每個子圖比較幾種排法：方格、由左到右或由上到下的分層流程、折成蛇形的長流程，以及「環形」：主迴圈繞成長方形（重設狀態在左上、順時針走），掛在旁邊的短迴圈排成小三角形或小方形貼在出發的狀態旁。全部用同一套分數挑最好的：交叉最重要，再來是穿過狀態的線、重疊的標籤、不是正三角形的互指三角形、沒和任何狀態對齊的狀態、太長的箭頭、在重設狀態左邊的狀態、逆著主流程的線、斜線、線長，以及形狀（略寬於高，像螢幕）。這些權重是依使用者在成對排法中的選擇調整的。局部調整：有兩個狀態互指的三角形排成正三角形（在環形裡只左右滑動，保持每排水平），兩個共用一邊的拼成菱形；有長箭頭的狀態會試著移到離鄰居較近的空格。若還有交叉、重疊或穿過狀態的線，會試著拉開間距修正；修不掉的會在畫面下方提示。狀態都會對齊 20px 格線；擋到狀態的線改成弧線，自迴圈朝最空的一側。匯入 Verilog 時也用這套規則；每次排版都可以復原。

線上文字（右下角「全部／隱藏」）：條件太長時可以先隱藏，選取某條線時仍會顯示它的文字方便編輯；匯出的 PNG、SVG、LaTeX 也照這個設定。排版時會考慮目前的設定，所以隱藏文字後再排版會更緊湊。

匯出（File ▸ Export）：PNG（2 倍解析度）、SVG、LaTeX（TikZ `automata`，可複製或存成 `.tex`）。這三種都由 `@fsm/core` 的 `renderSvg` / `renderLatex` 產生，和 MCP server 匯出的結果一致。

## 檔案

圖存成 `.fsm.json`（格式見 `packages/core/src/model.ts`），可以和 MCP server 互通。目前編輯中的圖也會自動備份在 WebView 的 localStorage，重開程式會還原。

## 線上版（claude.ai 頁面）

`node apps/editor/scripts/build-single.mjs` 會把編輯器打包成單一 HTML（`apps/editor/artifact/fsm-designer.html`），發布在 https://claude.ai/artifact/1yLyxqEDCALhfjM9eFgMep 。在那個頁面裡存檔/匯出會先跳出確認視窗；`.tex` 不在允許的副檔名內，所以 LaTeX 會存成 `.tex.txt`（或用「複製」）。
